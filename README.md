# Ball-Beam-Project
This project demonstrates a balance beam system that balances a ball in the middle of a tube.  
## Relevent Folders:
Dr. Morton's Code
- This folder contains the test code that Dr. Morton created.  It controls the servo using switches.
LED Display & Busser Code
- This folder contains the code for Aden's LED display and Busser
PID Controller Code
- This folder contains the code and math for Gregs PID controller
VGA Display Code
- This folder contains the code for the VGA display port.
